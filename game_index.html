วิธีเลือกเกม
  1. เลือกประเภทเครื่องเกม จากนั้นเกมในประเภทนั้นจะแสดงขึ้นมา
  2. คลิกที่รูปเกมเพื่อเลือก ✓ — คลิกซ้ำเพื่อยกเลิก
  3. เลือกได้สูงสุด 10 เกม จากทุกประเภท
  4. กด "ใช้รายการนี้" เพื่อแนบรายการเกมไปในข้อความแจ้งให้ทางร้านติดตั้ง
  5. หรือ กด "สร้างข้อความเพื่อแจ้งภายหลัง" และกด "Copy รายการ" แล้วส่งมาที่ Line @ajgame

* กดปุ่ม "กดเพื่อดูเกมได้เต็มจอ" เพื่อซ่อนคำแนะนำด้านบนและเลือกเกมง่ายขึ้น

☁️ Cloud Sync — GitHub Gist

เก็บข้อมูลใน GitHub Gist — ไม่มี SHA conflict, ทำงานทุก browser ✅

วิธีสร้าง Token (ทำครั้งเดียว):
1. GitHub.com → รูปโปรไฟล์ → Settings
2. เลื่อนล่างสุด → Developer settings
3. Personal access tokens → Tokens (classic)
4. Generate new token (classic)
5. ติ๊ก scope: gist → Generate → Copy token
6. วาง token ด้านล่าง แล้วกด 🆕 สร้าง Gist อัตโนมัติ
📱 วิธีให้ทุก Device Sync อัตโนมัติ
Device ใหม่: เปิด Admin → Cloud Sync → กรอก Gist ID เดิมที่ได้จากการสร้าง → กด Sync
Auto ทุก device: วาง Gist ID ใน DEFAULT_GIST_ID ใน HTML แล้ว redeploy
