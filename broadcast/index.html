ข้อความ Flex

สร้าง Bubble หรือ Carousel ใส่รูป หัวข้อ ราคา ปุ่มเปิดเว็บ ปุ่มส่งข้อความ หรือ Postback ได้ แก้ JSON โดยตรงเพื่อใช้โครงสร้าง Flex ที่ LINE รองรับ

คัดผู้รับ

ส่ง Flex ให้ผู้ติดตาม LINE OA ทั้งหมดได้โดยไม่ต้องรู้ LINE Unique ID หรือเลือกกลุ่มลูกค้าที่ผูกบัญชีแล้ว, VIP, ภาษา และวันเริ่มเช่า พร้อมกรองด้วย Label ของ AJ

ควบคุมการส่ง

ดูจำนวนผู้รับก่อนส่ง จำกัด Maximum ตั้งเวลาประเทศไทย ส่ง Test ให้แอดมิน บันทึกร่าง และติดตามจำนวนส่งสำเร็จ/ล้มเหลว

ไอเดียแคมเปญ

โปรรายเครื่อง, ชุดเครื่องพร้อมเกม, Flash Deal, คูปองกลับมาเช่า, แนะนำเครื่องใหม่ และการ์ด Carousel เปรียบเทียบราคา ใช้ลิงก์ UTM ในปุ่มเพื่อติดตามการคลิก

Preview ในเว็บเป็นตัวอย่างใกล้เคียง LINE; ส่ง Test เพื่อดูหน้าตาบนอุปกรณ์จริง ก่อนส่งให้ลูกค้า

Broadcast ไปยังผู้ติดตาม OA ทั้งหมดใช้ LINE Messaging API โดยไม่ต้องมี LINE Unique ID; ไม่สามารถใช้ Label ของ AJ หรือจำกัดจำนวนผู้รับได้ และขึ้นอยู่กับโควตา LINE
